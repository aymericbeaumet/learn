# Intro

Programming is becoming more and more prevalent in our current society. It is a
skill that can be learned and practiced, but the massive amount of information
makes it hard to know where to start.

This course aims at teaching you the practical foundations of programming, it
will also give you the keys so you can pursue the learning by yourself.

We are going to learn how to code with the JavaScript language. JavaScript is
literally present everywhere: in your web-browser, in the servers, in embedded
devices, etc. It has a simple syntax and allows for a great learning experience
as you can immediately start playing with it to create your own projects.

What you are reading right now is a comment, it will be ignored when the code is
executed. Comments are very useful to explain what your code is doing.
