# Variables: Numbers

Storing text in variables is convenient, but what if you need to count
things? In this case you would want to use numbers.

You would input numbers with digits from 0 to 9.

It is possible to perform arithmetic operations on numbers:

- addition with +
- subtraction with -
- multiplication with \*
- division with /
- modulo with %
- raise to the power with \*\*

```js
// Declaring a variable with the amount of money I have
let money = 25;

// Adding my salary to my money!
money = money + 100;

// Bought some chocolate, removing the price from my money;
money = money - 5;

money; // `money` is now equal to 120
```
