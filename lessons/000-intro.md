# Intro

Programming is becoming more and more prevalent in our current society. Most
individuals and companies are now dealing with technical concepts at some point
of their lives. Having an understanding of how things work under the hood will
give you a better grasp at the big picture.

Programming is a skill that can be learned and practiced, but the massive amount
of information on the topic makes it hard to know where to begin. This
interactive course aims at teaching you the practical foundations of
programming. It starts from the ground up and expects no previous experience.

The entirety of the course will happen in this editor. This includes the
explanations, the exercices and the code you will write. It might be seem
disturbing at first, but an editor actually brings features that help you write
code, and it is important you familiarize yourself with this environment.

We are going to learn how to program with the JavaScript language. JavaScript is
literally present everywhere: in web-browsers, in servers, in embedded devices,
in video games, etc. It has a simple yet expressive syntax and allows for a
great learning experience as you can immediately start playing with it to create
your own projects in a wide variety of domains.

What you are reading right now is actually valid JavaScript code. More
specifically it is a multiline comment. Comments are used to document source
code, and they usually convey information that cannot be expressed otherwise.
Comments are only useful for other programmers, they are ignored during the
program execution.
